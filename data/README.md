# Derived example data

`phase_budget.csv` is generated by `python3 examples/phase_budget.py --csv data/phase_budget.csv`.

Rows are analytical scenarios, not experimental measurements or extracted paper data. Fields are uniform longitudinal perturbations; durations are assumed encoding intervals. The symmetric magnitude-loss column uses equal populations exposed to opposite fields. The pair-count column assumes independent phase noise of 0.01 rad per observation and a target ideal SNR of 5 for alternating-polarity measurements. It is not a statistical power calculation.

`synthetic_loop/` is generated by `python3 examples/current_phantom.py --output data/synthetic_loop`. It contains 75 points around an ideal square wire loop, their magnetic-field vectors, ideal bipolar spin-echo encoding, and the phase bias from a 100 microsecond waveform delay. The complete return circuit is included. The synthetic current amplitude is an arbitrary numerical example, not a stimulation prescription.

`encoding.csv` defines the piecewise-constant current and ideal signed sensitivity. `field_phase.csv` contains SI-valued predictions. `manifest.json` defines coordinates, phase/time conventions, limitations and hashes. There is no tissue conductivity solution, scanner acquisition, measured waveform, noise or voxel averaging. Regenerating the fixture should reproduce its files exactly in the same Python/math environment; cross-platform floating-point last digits may differ.

Published human and phantom datasets are linked in [the ecosystem audit](../docs/mreit-ecosystem.md); none have been downloaded or redistributed here. The [open-data contract](../docs/open-data.md) specifies the substantially richer records required for future measured data.
